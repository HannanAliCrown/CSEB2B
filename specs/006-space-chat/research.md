# Research: Space and Chat

- **Decision**: Keep Space publishing external and retain mobile interaction endpoints only.
- **Rationale**: Teams/Crown Solar publishes authoritative posts; the partner app reacts.
- **Alternatives considered**: Mobile post creation was rejected because it conflicts with the stated ownership model.
- **Chat boundary**: Partner and department parties share one thread model.
- **Unread**: Derived from a per-participant read mark, not stored as a counter, so it cannot drift from the messages.
