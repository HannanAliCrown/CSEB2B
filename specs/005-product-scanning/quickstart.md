# Quickstart: Product Scanning and Prizes

1. Test an unknown and blocked code in Authenticity Check.
2. Test a genuine code in Authenticity Check and confirm no claim/wallet entry.
3. Claim a winning code as Installer and Retailer and verify wallet credits.
4. Attempt Scan To Win as Wholesaler and Distributor and confirm refusal.
5. Scan the same code again for the same role and confirm duplicate refusal.
