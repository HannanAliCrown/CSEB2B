# Quickstart: Role-Based Dashboard

1. Run with mock data and sign in as Installer, Retailer, Wholesaler, and Distributor.
2. Confirm each Home screen displays the correct bottom navigation and tiles.
3. Run with `DATA_SOURCE=server` and verify slides/tickers are filtered by role and time.
4. Verify available/held wallet values agree with the ledger.
5. Verify deferred Branding shows no functional request flow.
