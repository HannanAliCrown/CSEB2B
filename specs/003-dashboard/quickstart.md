# Quickstart: Role-Based Dashboard

1. Start `prototype_server` against a database with `db/migrations` and `db/seed` applied (Home always reads from it).
2. Run the app with `DATA_SOURCE=server` and sign in as Installer, Retailer, Wholesaler, and Distributor.
3. Confirm each Home screen displays the correct bottom navigation and tiles.
4. Verify slides/tickers are filtered by role, active flag, and time window.
5. Verify available/held wallet values agree with the ledger.
6. Verify the Shop Branding tile opens the Shop Branding module.
