# Data Model: Inaam Rewards

- **SpinConfig/SpinPrize**: active configuration, segments, weights, scans-per-spin.
- **Spin**: account, config, selected prize, amount, timestamp, wallet entry.
- **ItemScheme/SchemeTier/Claim**: product scope, measure, thresholds, reward, one claim.
- **RewardProgram/ProgramTier**: period, product scope, scan targets, bonus, prior award.
