# Quickstart: Profile, Preferences, and PIN Security

1. Open Profile and verify identity fields and QR screen.
2. Sync contacts and confirm only registered partners remain.
3. Set and enable a four-digit PIN, restart with a valid session, and verify the gate.
4. Test wrong PIN, disable PIN, and change PIN.
5. Change language/theme and confirm they apply globally.
6. Tap support and verify the phone dialer opens with the stored number.
